EXPLICAÇÃO TÉCNICA (OPCIONAL)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

O que foi corrigido no código:

ANTES (ERRADO):
```typescript
const qtyNumber = parseFloat(food.qty); // "2 unidades" → 2 (errado)
const clinical_mass = qtyNumber; // 2g (absurdo!)
```

DEPOIS (CORRETO):
```typescript
const qtyStr = food.qty || '100';
const qtyMatch = String(qtyStr).match(/[\d.]+/); // Extrai número
const qtyNumber = qtyMatch ? parseFloat(qtyMatch[0]) : 100;

// Se qty tem "g" ou "ml", usar como massa clínica
const hasMassUnit = /\d+\s*(g|ml)/i.test(String(qtyStr));
const clinical_mass = hasMassUnit ? qtyNumber : 100;
```

Agora:
- "100g" → clinical_mass = 100g ✅
- "2 unidades" → clinical_mass = 100g (padrão) ✅
- "1 fatia" → clinical_mass = 100g (padrão) ✅
- "à vontade" → clinical_mass = 100g (padrão) ✅
